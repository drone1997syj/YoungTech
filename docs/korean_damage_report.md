## 3. 손상 원인 (실측)

### 3.1 확인된 사실

`git HEAD` 버전과 작업 트리의 손상 개수가 **완전히 일치**합니다
(`server/index.js` → 양쪽 모두 121개 `???`).

**즉 이 손상은 최근 작업 중에 생긴 것이 아니라, 이미 커밋된 상태로 존재했습니다.**

### 3.2 이중 인코딩 흔적

`ShopContext.jsx` 167행에서 전형적 패턴이 발견됐습니다.

```
현재:  ?붿껌 泥섎━???ㅽ뙣?덉뒿?덈떎.
```

원본 바이트를 보면 `\xeb\xb6\xbf\xea\xbb\x8c`(UTF-8 "붿껌")처럼
**UTF-8 바이트를 CP949로 잘못 해석한 뒤 다시 UTF-8로 저장**된 흔적입니다.

### 3.3 복구 불가 이유

앞부분이 이미 `?`(0x3F)로 치환돼 **원본 바이트가 소실**됐습니다.
`?붿껌`은 `요청`의 잔해지만, `?`는 어떤 바이트였는지 알 수 없습니다.
